# Unix Timestamp Converter

A Python-based command-line tool for converting dates and times to Unix timestamps and vice versa.

## Features

- Converts dates and times to Unix timestamps.
- Converts Unix timestamps to UTC date and time.
- Supports multiple date formats.
- Validates user input and handles invalid values.
- Allows multiple conversions in a single session.

## Usage

Run the program using:

```bash
python main.py
```

Select one of the following options:

1. **DateTime to Unix Timestamp:** Converts a date and time into a Unix timestamp.
2. **Unix Timestamp to DateTime:** Converts a Unix timestamp into a UTC date and time.
3. **Exit:** Closes the program.

## Supported Date Formats

- `YYYY-MM-DD HH:MM:SS`
- `YYYY-MM-DD`
- `DD/MM/YYYY HH:MM:SS`
- `DD/MM/YYYY`
- `MM/DD/YYYY HH:MM:SS`
- `MM/DD/YYYY`
- `DD-MM-YYYY HH:MM:SS`
- `DD-MM-YYYY`
- `YYYY-MM-DDTHH:MM:SS`
- `YYYY-MM-DDTHH:MM:SSZ`
